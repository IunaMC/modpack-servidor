# Changelog — v1.1.0-beta.01

## Added
- Add [Lightman's Currency](https://modrinth.com/mod/lightmans-currency) mod for the server's economy system
- Add [Polymorph](https://modrinth.com/mod/polymorph) mod to fix recipe conflicts caused by multiple mods adding the same recipe
- Add [MixinTrace Reforged](https://modrinth.com/mod/mixintrace-reforged) as the proper Forge port of MixinTrace
- Add [Leash](https://modrinth.com/mod/leash) mod
- Add [View Distance Fix](https://modrinth.com/mod/view-distance-fix) mod
- Add [Unsafe World Random Access Detector](https://modrinth.com/mod/unsafe-world-random-access-detector) mod to detect crash causes related to "You Shall Not Spawn!"

## Removed
- Remove [MixinTrace](https://modrinth.com/mod/mixintrace) (Fabric) since it's now handled through the Forge compatibility layer
- Remove [Better Recipe Book](https://modrinth.com/mod/better-recipe-book) due to bugs with [Tom's Storage](https://modrinth.com/mod/toms-storage)
- Remove [You Shall Not Spawn!](https://modrinth.com/mod/you-shall-not-spawn) mod due to an unresolved crash issue

- Add the changelog file MUDANCAS.md to the `.zip`
